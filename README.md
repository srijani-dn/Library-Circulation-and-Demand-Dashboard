# **Library Circulation and Demand Dashboard**



### Project Overview

The Library Circulation and Demand Dashboard is a menu-driven Python application designed to manage and analyse library borrowing records. It helps track book circulation, calculate borrowing durations, identify overdue books and analyse borrowing patterns.



### Features

1\. Add new library borrowing records.

2\. Display all borrowing records.

3\. Search records using student ID, book ID, loan ID or book title.

4\. Calculate borrowing durations using NumPy.

5\. Identify overdue books.

6\. Analyse book borrowing frequency.

7\. Generate category-wise borrowing summaries.

8\. Generate monthly borrowing summaries.

9\. Detect duplicate and incomplete records.

10\. Generate graphical representations of borrowing data.

11\. Export library reports in JSON format.



### Technologies Used

\- Python

\- NumPy

\- Pandas

\- Matplotlib

\- CSV

\- JSON



### Installation



Install the required Python libraries:



pip install numpy pandas matplotlib





### How to Run



1\. Download or clone this repository.

2\. Open the project folder.

3\. Run `main.py` using Python IDLE or another Python IDE.

4\. Select an option from the menu to use the application.



### Project Files



\- main.py – Main Python application.

\- library\_records.csv – Library borrowing records.

\- library\_report.json – Exported report.

\- graphs/ – Generated graphs and charts.
